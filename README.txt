راهنمای جایگزینی فایل‌ها (پروژه MinerTools / WhatsminerMonitor) — نسخه ۲
========================================================================

این چهار فایل اصلاح‌شده را در پروژه خودتان جایگزین کنید:

1) app/src/main/java/com/miner/whatsminermonitor/network/NetworkScanner.kt
   - رفع باگ اسکنر: Semaphore روی 25 اتصال همزمان (بازه مجاز 20-30)
   - بستن قطعی سوکت‌ها با Socket().use {} (بدون Socket Leak)
   - تایم‌اوت اتصال/خواندن 900ms (بازه مجاز 850-1000) برای پورت 4028 و 4433
   - سهمیه اسکن فقط برای پروب پورت رزرو می‌شود؛ خواندن کامل اطلاعات
     دستگاه سهمیه را اشغال نمی‌کند تا اسکن بقیه IPها کند نشود
   - اعلام نتیجه به UI به محض باز بودن پورت هر IP

2) app/src/main/java/com/miner/whatsminermonitor/network/WhatsminerClient.kt
   - خواندن ۱۰ endpoint هر دستگاه (summary ،devs ،stats ،version ،PSU،
     pools ،v3 ،error-code و...) به‌صورت «موازی» با سقف ۴ اتصال همزمان
     به هر دستگاه — قبلاً پشت‌سرهم با ۷۰ms مکث بود و به همین دلیل
     مرحله «در حال خواندن اطلاعات» چند ثانیه طول می‌کشید
   - پارس کردن و همه منطق‌های fallback دقیقاً مثل قبل است

3) app/src/main/java/com/miner/whatsminermonitor/ui/MinerViewModel.kt
   - نمایش فوری هر IP پیداشده به‌صورت ردیف موقت «در حال خواندن اطلاعات...»
     و جایگزینی با آمار کامل بعد از پایان queryMiner
   - رفرش زنده آمار (فن/دما/هش‌ریت) هر ۱۲ ثانیه حالا «موازی» انجام می‌شود
     (سقف ۶ دستگاه همزمان) — قبلاً پشت‌سرهم بود و با چند دستگاه هر دور
     رفرش خیلی طول می‌کشید و مقادیر روی صفحه ثابت به نظر می‌رسیدند

4) app/src/main/java/com/miner/whatsminermonitor/MainActivity.kt
   - مدرن‌سازی صفحه اصلی: کارت ماینرها، کارت خلاصه، نوار وضعیت اسکن، حالت خالی
   - توابع جدید: ScanStatusBanner ،SummaryTile ،MetricChip
   - صفحه جزئیات دستگاه عیناً با نسخه قبلی یکسان است
   - هیچ import جدیدی لازم نیست

نکات مهم:
- ساختار پوشه‌ها داخل این زیپ دقیقاً مثل ساختار پروژه است؛ می‌توانید
  مستقیم روی ریشه پروژه استخراج کنید (extract) و فایل‌ها جایگزین شوند
- بعد از جایگزینی حتماً: Build > Clean Project و بعد Rebuild Project
- به res/mipmap ، res/drawable و آیکون‌ها دست نزنید

تست سریع اینکه MainActivity واقعاً جایگزین شده:
در Android Studio فایل MainActivity.kt را باز کنید و Ctrl+F بزنید و
دنبال «ScanStatusBanner» بگردید. اگر پیدا نشد یعنی فایل جایگزین نشده.
